# Scripts

Helper scripts for data generation, analysis, and utilities.

## Common Scripts

- Data generation and preprocessing
- Experiment analysis and comparison
- Result visualization
- Model evaluation
- Performance benchmarking

## Usage

Run scripts from the project root:
```bash
python scripts/script_name.py [arguments]
```

## Guidelines

- Make scripts reusable and configurable
- Use argparse for command-line arguments
- Document usage in script docstrings
- Output to appropriate directories (data/, experiments/results/)
